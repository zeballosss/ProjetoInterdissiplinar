# Correcao para PostgreSQL 9.5

Este pacote foi ajustado para evitar a sintaxe de coluna `GENERATED BY DEFAULT AS IDENTITY`, que nao existe no PostgreSQL 9.5.

## Alteracoes realizadas

- `Usuario`: `GenerationType.SEQUENCE` com a sequencia `usuario_seq`.
- `Jogador`: `GenerationType.SEQUENCE` com a sequencia `jogador_seq`.
- `Favorito`: `GenerationType.SEQUENCE` com a sequencia `favorito_seq`.
- `Avaliacao`: `GenerationType.SEQUENCE` com a sequencia `avaliacao_seq`.
- Todas as sequencias usam `allocationSize = 1`.
- O `application.properties` inclui as propriedades `app.admin.email` e `app.admin.password`, que estavam ausentes no arquivo usado no computador da escola.
- A conexao padrao foi configurada com o banco `Enciclopedia_db`, usuario `postgres` e senha `postdba`.

## Configuracao

O arquivo `src/main/resources/application.properties` ja esta preenchido com os valores acima. Se o banco ou as credenciais forem diferentes, altere as tres propriedades `spring.datasource.*`.

## Primeiro teste

1. Confirme no pgAdmin que o servidor local esta ativo e que existe o banco `Enciclopedia_db`.
2. Abra a pasta do projeto no VS Code.
3. Execute `EnciclopediaCopaApplication.java`.
4. Verifique se o Hibernate cria as sequencias e as tabelas.
5. Acesse `http://localhost:8080`.

Conta administrativa padrao: `admin@copa.com` / `admin123`.

## Limite de compatibilidade

O PostgreSQL 9.5 e anterior a versao minima oficialmente suportada pelo dialeto padrao do Hibernate 6.6 (PostgreSQL 12). A mudanca para sequences corrige a incompatibilidade de sintaxe de identidade observada no log enviado, pois PostgreSQL 9.5 possui suporte a sequences. O Hibernate pode continuar exibindo um aviso sobre a versao antiga e nao ha como garantir compatibilidade oficial completa com todas as operacoes do Hibernate 6.6 nesse servidor. Se aparecer outro erro SQL durante a inicializacao, sera necessario avaliar a mensagem especifica.
